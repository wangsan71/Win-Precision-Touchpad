# v0.1.2 延遲優化說明

## 用戶回報

安裝版 v0.1.1 在功耗限制約 ≤20W 時，拖曳全程滯後（非僅起步）。

## 熱路徑瓶頸（Raw Input STA 執行緒）

1. **TouchpadRawInput.ParseInput** — 每次 `WM_INPUT` 重取 RIDI_PREPARSEDDATA、HidP_GetValueCaps 與 LINQ OrderBy（低功耗下 CPU 成本明顯）。
2. **TouchpadPipeline 詳細日誌** — 三指期間約每 40ms 字串格式化 + AppLogger AutoFlush 磁碟同步，與 SendInput 同執行緒。
3. **SendInput 合併** — 預設滑鼠移動合併在電源節流時可能感覺慢一拍。
4. **執行緒／進程優先權** — Raw Input 預設 Normal，低功耗下易被排擠。
5. 起步 settle frame 與 StartDistanceThreshold=12 — 主要影響起步（次要）。
6. 敏感度預設 0.6 — 屬位移增益感受，與延遲不同；預設未改。

## 程式變更（已納入 v0.1.2）

- 快取 HID preparsed 與排序後 value caps（`TouchpadRawInput`）
- 拖曳中抑制逐幀日誌；詳細日誌間隔 250ms
- 相對移動使用 `MOUSEEVENTF_MOVE_NOCOALESCE`；重用 SendInput 緩衝（`MouseInjector`）
- Raw Input 執行緒 `AboveNormal`；拖曳期間進程 `AboveNormal`（`DragProcessBoost`）
- 僅在剛新增接觸／仍在取得接觸時套用 settle（`DragEngine`）
- ContactTracker 重用列表；AppLogger INFO 緩衝寫入（WARN／ERROR 立即）
- 單元測試更新；20／20 通過

## 設定建議（未改預設）

- 若行程仍偏短：敏感度 0.8–1.2
- 若起步仍黏滯：開始距離閾值 6–8
