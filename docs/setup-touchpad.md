# 手動將三指手勢設為「無」（Win11）

**重要：** 本專案**唔會**自動改註冊表或系統設定。請自己喺設定 App 改。

相關：[testing.md](testing.md)｜[architecture.md](architecture.md)｜[README](../README.md)

## 步驟（Windows 11）

1. 開 **設定**（`Win + I`）。
2. 去 **藍牙與裝置** → **觸控板**（有啲機寫「Touchpad」）。
3. 撳入 **三指手勢**（Three-finger gestures）。
4. 將下列項目設為 **無 / Nothing**（或「無動作」）：
   - 向上撥／向下撥／向左撥／向右撥（或「滑動」相關選項）
   - 若有「輕觸」／「點擊」三指選項，亦建議暫時設為無，避免同 Raw Input／三指拖搶。
5. （可選）**四指手勢**可暫時保留系統預設；v1 唔處理四指（App 只 log `FourFingerReserved`）。

## 點驗證已關

- 三指左右滑：**唔應**再切虛擬桌面／工作檢視（視你原本設定）。
- 開 `WinTouchpad.Tray` 後，三指喺觸控板郁動：
  - 日誌應出現 `contacts=3 ...`
  - 啟用拖曳時可拖游標下視窗／選字（見 [testing.md](testing.md) M2）

## 測完想還原

返同一頁設定，將三指手勢改返你鍾意嘅系統動作即可。

## 常見問題

| 現象 | 處理 |
|------|------|
| Tray 話「未偵測到 Precision Touchpad」 | 確認機有 PTP；外接滑鼠唔代替；裝置管理員睇「人體學輸入裝置」／HID |
| 有註冊但 log 無 contacts=3 | 確認三指已設「無」；試前景開住日誌窗再三指滑 |
| 只有 1–2 指 log | 正常；三指拖曳要三指同時 |
| 拖曳太快／太慢 | 開設定窗調敏感度（預設 **0.6**）；唔跟系統游標速度 |
| 拖唔到管理員視窗 | 以系統管理員執行 Tray，或降低目標視窗權限 |
